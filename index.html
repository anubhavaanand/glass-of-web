How the technique works: A displacement map PNG is generated once for each glass shape. An SVG feDisplacementMap reads its R channel (horizontal bend) and G channel (vertical bend). The filter is applied via CSS filter: url(#id) to the lens itself — a small div that contains a copy of the content offset to the correct position. Moving the lens only updates its transform and the copy's offset. Dynamic filter IDs prevent Safari's rendering-cache freeze on every shape change.
